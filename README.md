# combiner_SBE_PyroScience
Outil pour combiner les données de la sonde SBE19 et PyroScience AquaPhox-L

Instructions : 

1. Téléchargez le fichier combiner_sbe19_aquaphox.py.

2. Installer uv

   Linux : Dans un terminal, entrez ``sudo snap install astral-uv --classic``
   
   Windows : Ouvrir PowerShell. Tapez ``powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"``. Fermez puis rouvrez PowerShell.
   
3. Lancer le script

   Dans le terminal ou PowerShell, tapez ``uv run combiner_sbe19_aquaphox.py`` et suivez les instructions.
